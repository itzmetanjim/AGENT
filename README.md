# 🛡️ WebSec GPT

**An Advanced AI-Powered Security Assistant**

WebSec GPT is a full-stack AI application designed to provide intelligent security insights, similar to Google’s Gemini, but specialized for web security and development contexts. Built with a modern **TypeScript** frontend, this tool helps developers identify vulnerabilities and understand complex security protocols through interactive AI.

---

## 🚀 Features

* **AI-Powered Chat:** Real-time security analysis and code explanation using advanced LLMs.
* **Secure Authentication:** User accounts with secure login and registration flows.
* **TypeScript Core:** Robust and type-safe frontend for a smoother user experience.
* **Vulnerability Detection:** Specialized prompts for identifying common security bugs like SQL injection and XSS.

---

## 🛠️ Tech Stack

* **Frontend:** React / Next.js with **TypeScript**
* **Styling:** Tailwind CSS
* **Backend:** Node.js & Express / FastAPI
* **Database & Auth:** Supabase / PostgreSQL
* **AI Engine:** Integrated AI SDKs (OpenAI / Gemini / Anthropic)
